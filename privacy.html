개인정보처리방침 — 오늘의 붓다 업로더

시행일: 2026년 10월 29일

'오늘의 붓다 업로더'는 채널 운영자 한 사람이 자기 유튜브 채널 오늘의 붓다(@ajjabuddha)에 직접 만든 영상을 예약 업로드하려고 쓰는 개인용 스크립트입니다. 다른 사람이 쓰는 앱이 아닙니다.

  • 사용하는 권한: YouTube Data API v3의 영상 업로드 권한(youtube.upload) 하나뿐입니다.
  • 모으는 정보: 없습니다. 다른 사용자의 정보나 유튜브 데이터를 읽거나 모으거나 저장하거나 공유하지 않습니다.
  • 저장하는 것: 운영자 본인의 OAuth 갱신 토큰 하나뿐이며, 암호화된 GitHub Actions 비밀값에 보관합니다.
  • 권한 철회: Google 계정 → 서드 파티 연결에서 언제든 접근 권한을 없앨 수 있습니다.

이 스크립트가 Google API에서 받은 정보를 쓰고 다른 앱으로 넘기는 방식은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 유튜브 이용에는 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

Privacy Policy — 오늘의 붓다 Uploader

"오늘의 붓다 Uploader" is a private, single-user script used only by the channel owner to schedule uploads of their own original videos to their own YouTube channel, @ajjabuddha. It is not offered to other users.

  • Scope used: YouTube Data API v3, https://www.googleapis.com/auth/youtube.upload only.
  • Data collected: none. The script does not read, collect, store, display or share any YouTube data or any other user's data.
  • Data stored: only the owner's own OAuth refresh token, kept as an encrypted GitHub Actions secret.
  • Revoking access: at any time via Google Account → Third-party connections.

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using YouTube you agree to the YouTube Terms of Service; see also the Google Privacy Policy.
